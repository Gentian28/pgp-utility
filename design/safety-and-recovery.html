PGP Utility safety and recovery

Approved proposal, implemented locally; release verification pending

Keep the existing five tabs and theme. Add explicit safety states, key backup and lifecycle actions. Nothing connects to a network. The examples use synthetic identities.

Implementation notes: the Keys detail pane is 360 logical pixels and stacks below the list under 760. Confirmation panels have 16-pixel padding. Scroll spacing belongs to the content so narrow layouts measure within their viewport. Private-key and certificate disclosures are separate. Inputs, key rows, expanders and date controls have accessible names. The footer includes the app version, runtime and local-only status. Live Windows inspection is in progress; this remains a proposal until verified and released.

Text

The action, key and passphrase controls wrap at narrow widths. A changed input immediately clears output and verdict. A verdict replaces the empty output editor and scrolls within the output region at short heights. Copy is disabled when there is no output text. Lifecycle caveats appear directly below the verdict heading. All signature results include the validated primary fingerprint and the same trust explanation used for files.

Keep the file and signature controls. Use the same verdict component as Text. A changed file, signature, key or action clears the old verdict. Existing signature files are preserved. The verdict applies to the bytes read during the check; external edits require another check.

Backup and restore states
Back up your keys

The ZIP contains private keys with their existing protection and stored revocation certificates. It has no additional password. Keep it offline, protect access, and test a restore. Existing backup files are preserved.

Restore a backup

Keys are validated before import. Existing revocations and newer certificates are retained. Existing private-key protection stays unchanged; restore into an empty store to use an older backup passphrase. Restoring does not delete other keys.

Restore complete

2 identities restored. Test a previously encrypted message to confirm access, then store the backup safely.
